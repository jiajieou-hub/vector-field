# 界面元素样式分类

这份清单把 `index.html` 里的按钮、开关、分段切换、滑块、输入框和浮层卡片，按「长得一样」分成几类，并列出每一类包含哪些元素、样式写在哪里。

**怎么用：** 想改某一类的样式时，先在这里找到这一类，再对照列表把每个元素都看一遍，决定哪些要跟着改。这份清单只记录现状，**不代表这些元素应该共用同一条样式**：同一类里经常有尺寸、圆角或状态不同的变体，有的外观相同但 CSS 是分开写的，一起改之前要逐个确认。

**行号**是 `index.html` 当前版本的行号：样式表在第 40–928 行，后面是 HTML 和脚本。改动以后行号会偏移，用选择器搜索更可靠。「脚本生成」表示元素不在 HTML 里，是脚本运行时创建的。

## 1. 胶囊按钮

凸起的胶囊：浅色边框、半透明底、顶部一层淡高光；悬停时上浮 2px 并提亮，按下时缩小回弹。

尺寸规则在第 158–161 行（高 34px、圆角 10px）。底色另外换成了毛玻璃，和大卡片一样，覆盖了基础外观的底色。`.act.ic` 是圆形图标款（第 107 行）。
